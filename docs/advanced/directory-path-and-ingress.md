# 目录路径前缀与入站继承

## 线上影响（必读）

| 项 | 影响 |
|---|---|
| DDL | **必须先执行** `flow-api/sql/20260811_directory_path_prefix_security*.sql` 再发版；否则查目录表会因缺列失败 |
| 存量目录全 NULL | **无行为变化**（入站仍接口→全局；新建无目录前缀） |
| 配置目录 `security_config` 后 | 其下接口未覆盖字段**立即**按目录生效（与接口「改完需发布」不同） |
| `path_prefix` | 只影响编辑期路径前缀展示与提交拼接；**不自动改**已有接口 path、不改运行时路由 |

## 功能摘要

1. 目录弹框：基本信息 / pathPrefix / 访问控制（入站限流、IP、超时、鉴权、谁可以调用、出站隐私）
2. **多层 pathPrefix：根→叶叠加**（非就近覆盖）。例：根 `/api/public` + 子 `/v1` → 有效前缀 `/api/public/v1`
3. **路径模型 B**：输入框只填相对段；`addonBefore` = `SYSTEM_PREFIX` + 目录有效前缀；保存时拼成完整 `url` 入库
4. 目录树支持右键：新建接口 / 从宿主导入 / 新建子目录 / 编辑 / 删除；工具栏新建需先选中目录
5. **批量按目录前缀重写**：接口列表勾选后「按目录前缀重写」——剥离旧前缀（默认取勾选 URL 最长公共前缀）、拼上各接口所属目录当前有效前缀，只改草稿；已发布需再发布才上线；WRAP 跳过
6. 入站：`接口 → 目录链 → 全局`

详见 [入站防护](./ingress-security.md)。
